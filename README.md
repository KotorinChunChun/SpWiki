# SpWiki 1.0

SharePoint Online のドキュメント ライブラリに置いた Markdown (`.md`) と
HTML (`.html`) を、GitHub Wiki のような感覚で閲覧するための SPFx ソリューションです。

- **ファイルはライブラリのまま。** 別のシステムに移す必要はありません
- **`.md` と `.html` を同じ体裁で表示**します。相互にリンクできます
- **相対リンクでドキュメント間を行き来**できます（`install.md` / `../README.md`）
- **URL で共有**できます（`?file=guide/install.md`）
- **`## 目次` と書くだけで目次を自動生成**します。見出しは折りたためます
- **タグ（最大 3 列）を付けてライブラリ全体から横断検索**できます
- **ページ名でも本文でも検索**できます
- **☰ メニューからページの新規作成・移動**ができます
- **目次とファイル ツリーを左に固定**して読み進められます
- **フォルダー単位・ファイル単位で限定公開**にできます
- **マニュアルを同梱**しているので、ヘルプはこの画面から読めます
- ライブラリの**右クリック メニューからも開けます**

## 何ができるか

### 表示

見出し・段落・箇条書き・表・コードブロック・画像・リンク・引用・チェックリストなど、
GitHub Flavored Markdown の主要な記法に対応します。
コードは JavaScript / TypeScript / PowerShell / JSON / HTML / CSS / SQL / C# の
8 言語を色分けします。

`.html` / `.htm` のファイルも同じように表示できます。Markdown 変換を通さずに
そのまま描画しますが、リンク解決・画像解決・見出しの id 付与・コードの色分け・
サニタイズは `.md` とまったく同じ扱いです。見た目もビューアー側の体裁に揃うため、
ファイルに書いた `<style>` や `style` 属性は反映されません
（→ [執筆者ガイド](docs/WRITERS_GUIDE.md)）。

### 移動

本文中の相対リンクをたどると、ページを再読み込みせずに次のドキュメントへ移動します。
`.md` から `.html`、`.html` から `.md` のように形式をまたいでも同じです。
ブラウザーの戻る・進むもそのまま使えます。

### 共有

表示中のドキュメントの URL がそのまま共有 URL です。

```
https://<テナント>.sharepoint.com/sites/docs/SitePages/SpWiki.aspx?file=guide/install.md
```

### 目次と見出し

`## 目次` という見出しを置くと、その下にページ内の見出しツリーが自動生成されます。
見出しはクリックで折りたたみでき、右のアイコンでその見出しに直接飛ぶ URL をコピーできます。

### タグ

ライブラリの列にタグを保存します。タグの列は**最大 3 つ**設定でき、ファイル名の下に 3 段で並びます。
タグをクリックすると、そのタグが付いたページをライブラリ全体から検索して一覧にします。
列名をクリックすればその場で付け外しでき、列が許可していれば一覧に無いタグも追加できます。

### ページの作成と移動

左上の **☰** メニューから、現在のフォルダーの一覧を見ながら `.md` / `.html` のページを作れます。
ひな形が入った状態で作られ、そのまま編集画面へ移ります。
ヘッダーのファイル名かフォルダーをクリックすると、名前の変更とフォルダーの移動ができます。

### 4 つの見せ方

| 形 | 用途 |
| --- | --- |
| ページに Web パーツを配置 | 標準。サイトのナビゲーションと一緒に見せる |
| ページ URL に `?env=WebView` を付ける | ナビゲーション類を隠して本文だけを大きく見せる |
| Single Part App Page に変換 | 利用者にページを編集させたくない場合 |
| ライブラリのツールバー／右クリック | ページを開かずにモーダルで読む |

## 役割ごとにやること

### テナント管理者

1. `.sppkg` をアプリ カタログにアップロードして展開する
2. ライブラリのコマンドを使うなら「テナント全体の拡張機能」に 1 行登録する
3. 「デスクトップ アプリで編集」を使うなら `spmd:` 対応アプリを用意する（任意）

→ 詳細は [管理者ガイド](docs/ADMIN_GUIDE.md)

### 書く人（ライター）

1. ライブラリに `.md`（または `.html`）を置く。フォルダー構成がそのままリンクの基準になる
2. 相対リンクで相互に繋ぐ
3. 画像はライブラリ内に置いて相対パスで参照する
4. タグを付けて横断検索できるようにする

→ 詳細は [執筆者ガイド](docs/WRITERS_GUIDE.md)

ページを開くだけです。使い方は下の「かんたんな使い方」を参照してください。

→ 詳細は [利用者ガイド](docs/USERS_GUIDE.md)

## かんたんな使い方

### 開く

管理者から案内されたページの URL を開きます。

```
https://<テナント>.sharepoint.com/sites/docs/SitePages/SpWiki.aspx
```

### 別のドキュメントへ移動する

本文中のリンクをクリックするだけです。**ブラウザーの戻るボタンで前のドキュメントに戻れます。**

### 今見ているドキュメントを人に送る

**アドレス バーの URL をそのままコピーして送ってください。** 相手も同じドキュメントが開きます。

### 右上のボタン

| ボタン | 動作 |
| --- | --- |
| **編集** | SharePoint の編集画面を新しいタブで開く |
| **アプリで開く** | `spmd:` に対応したアプリに渡す。Web パーツの設定で表示を有効にした場合のみ（既定は OFF） |

ファイル名の左には 2 つのアイコンがあります。

| アイコン | 動作 |
| --- | --- |
| **目次** | クリックでポップアップ、ダブル クリックで左に固定 |
| **鍵** | 開いていれば上のフォルダーの設定を引き継ぎ、閉じていれば限定公開。クリックで確認・変更 |

左上の **☰** も同じで、クリックでポップアップ、ダブル クリックで左に固定です。
左のペインは 1 つなので、目次とファイル ツリーは入れ替わります。

ファイル名の右のフォルダーはパンくずです。`guide / api` のそれぞれが
そのフォルダーを開くリンクになっています。

### ライブラリから直接開く

ドキュメント ライブラリで `.md` か `.html` を選び、ツールバーか右クリック メニューから選びます。
（「Markdown プレビュー」という名前ですが、`.html` でも同じように開けます。）

| コマンド | 動作 |
| --- | --- |
| **SpWiki で開く** | ビューアー ページへ移動 |
| **Markdown プレビュー** | その場でモーダルを開いて読む |
| **デスクトップ アプリで編集** | パソコンのエディターで開く |

## フォルダー構成

```text
SpWiki/
├─ README.md       製品概要
├─ docs/           利用・管理・開発ガイド
├─ src/            Web パーツと拡張機能
├─ config/         SPFx ビルド設定
├─ tests/          単体テスト
│  ├─ fixtures/    サンプル文書
│  └─ harness/     ローカル確認画面
└─ dev/
   └─ scripts/     ビルド・検証・配布スクリプト
```

ビルド方法は [開発者ガイド](docs/DEVELOPERS_GUIDE.md)、
コマンド一覧は [ビルドコマンド](docs/BUILD_COMMANDS.md)を参照してください。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| フレームワーク | SharePoint Framework (SPFx) 1.23.2 |
| 言語 | TypeScript（React 不使用 / Pure HTML） |
| Markdown → HTML | [marked](https://marked.js.org/) |
| サニタイズ | [DOMPurify](https://github.com/cure53/DOMPurify) |
| ハイライト | [highlight.js](https://highlightjs.org/) |
| 構成要素 | Web パーツ 1 つ ＋ ListView Command Set 1 つ |

Markdown から変換した HTML も、ライブラリに置かれた `.html` の中身も、必ず同じ
DOMPurify の設定を通してから表示します。`<script>` `<iframe>` `<object>` `<form>`
`<style>` や `onerror` などのイベント属性、`style` 属性、`javascript:` リンクは
除去されます。

## 1.0 の機能

初版で提供する機能と対応範囲です。

| 機能 | 状態 |
| --- | --- |
| Markdown 表示 / 相対リンク解決 / URL 更新 / 戻る・進む | 対応 |
| HTML (`.html` / `.htm`) 表示 | 対応 |
| 目次の自動生成 / 見出しの折りたたみ / 見出しリンクのコピー | 対応 |
| 目次ボタン（ポップアップ / 左に固定） | 対応 |
| タグ 3 列 / タグ バー / タグ検索 | 対応 |
| タイトル（ホームに戻る）/ ファイル名 / フォルダーのパンくず | 対応 |
| ☰ メニュー（フォルダー ツリー・新規作成・リネーム・左に固定） | 対応 |
| フォルダーをページとして開く（ツリー表示・タグ・アクセス許可） | 対応 |
| 特殊見出し 4 種（タグ / サブページ / ページツリー / 関連ページ） | 対応 |
| 検索ページ（ページ名 / 本文、フォルダー指定、限定公開のみ） | 対応 |
| アクセス許可の確認と変更（限定公開） | 対応 |
| 同梱マニュアルのヘルプ ページ | 対応 |
| コードブロックのコピー ボタン | 対応 |
| 404・読込中の表示 / サニタイズ / コード ハイライト | 対応 |
| 編集ボタン / `spmd:` でのアプリ連携 | 対応 |
| ライブラリのコマンド（フルページ / モーダル / アプリ） | 対応 |
| Mermaid 描画 / PDF 出力 | 対象外 |
