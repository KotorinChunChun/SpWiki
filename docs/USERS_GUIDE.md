# 見る人（ユーザー）向け

対象: SpWiki 1.0。文中の人名・テナント名は説明用のサンプルです。

SharePoint 上の Markdown（`.md`）と HTML（`.html`）のドキュメントを読むためのビューアーです。
どちらの形式でも同じ見た目で表示され、操作も同じです。
**特別な準備は要りません。** ページを開くだけで使えます。

---

## 開く

管理者から案内された URL を開きます。

```
https://<テナント>.sharepoint.com/sites/docs/SitePages/SpWiki.aspx
```

最初に表示されるのはたいてい `README.md`（目次にあたるページ）です。

---

## 読み進める

### リンクで移動する

本文中のリンクをクリックすると、次のドキュメントが表示されます。
ページ全体は再読み込みされないので、待ち時間はほとんどありません。

### 戻る・進む

**ブラウザーの戻る／進むボタンがそのまま使えます。** リンクを辿った履歴を行き来できます。

### 外部サイトへのリンク

`https://` で始まるリンクは、**新しいタブ**で開きます。読んでいた場所を見失いません。

### 左上の ☰ メニュー

画面左上の **☰** を押すと、いまいる場所のフォルダーと、同じフォルダーにあるファイルの一覧が出ます。
クリックするとそのページへ移動します。フォルダーを押すと、そのフォルダーの中身に切り替わります。

一番上の **「新しいページを作成」** を押すと、ファイル名・形式（`.md` / `.html`）・
作成後にどこで編集するかを聞かれます。「作成」でひな形（見出しと `目次`）付きのページができ、
そのまま編集画面に移ります（ライブラリの編集権限が必要です）。

| 作成後 | 動作 |
| --- | --- |
| **SharePoint で編集** | SharePoint の編集画面に移ります。戻るボタンでビューアーに戻れます |
| **アプリで編集** | パソコンのエディターが起動します。画面はビューアーのままです |

### 見出しの折りたたみ

**見出しをクリックすると、その見出しの内容を折りたためます。** もう一度押すと開きます。
長いページで必要なところだけ読みたいときに使ってください。

内側の見出しを畳んだ状態は、外側を開き直しても畳んだままです。

### 見出しへのリンクをコピー

見出しにマウスを乗せると、右に **コピー アイコン** が出ます。
押すと**その見出しに直接ジャンプする URL** がクリップボードに入ります。そのまま人に送れます。
受け取った人がその URL を開くと、**その見出しの位置まで自動でスクロールします。**

### 目次

ページに「目次」という見出しがあると、**その下に自動で目次が作られます。**
書いた人が見出しを増やしても、目次は自動で追いつきます。

---

## 人に送る

**アドレス バーの URL をそのままコピーして送るだけです。**

```
https://<テナント>.sharepoint.com/sites/docs/SitePages/SpWiki.aspx?file=guide/install.md
```

リンクを辿って移動するたびに、アドレス バーの `?file=` の部分が今見ているドキュメントに
書き換わります。**深い階層のドキュメントでも、その場で URL をコピーすれば相手に届きます。**

> 相手にもそのライブラリの閲覧権限が必要です。権限が無い場合は表示できません。

---

## 画面の見方

```
┌──────────────────────────────────────────────┐
│ ☰  SpWiki                 [編集] [アプリで開く] │  ← タイトル（押すと先頭へ）
│ ▤ 🔓 install.md   guide / api                 │  ← 目次・鍵・ファイル名・パンくず
├──────────────────────────────────────────────┤
│ タグ   (設計) (SPFx)                           │  ← 付いているタグ
│ 分類   (手順書)                                │     列名を押すと編集
│ 担当   (山田)                                  │     タグを押すと検索
├──────────────────────────────────────────────┤
│  # インストール手順                            │  ← 本文
│  ## 目次                                      │
│   ・前提条件 / 手順 / ...                       │  ← 自動生成
│  ...                                         │
├──────────────────────────────────────────────┤
│ ページ: guide/install.md                       │
└──────────────────────────────────────────────┘
```

**ここまでの部分（タイトル・ファイル名・タグ）は、本文をスクロールしても動きません。**
今どのページを見ているのかを見失わずに読み進められます。

一番上は**このビューアーの名前**です（管理者が設定します）。
**押すと最初のページに戻ります。**

その下がファイル名と、それが入っているフォルダーです。
**ファイル名を押すと、名前と場所を変える画面**が出ます。

### フォルダー名はパンくずです

`guide / api` のように出ているところは、**それぞれが別のリンク**です。

- `guide` を押すと `guide` フォルダーが開きます
- `api` を押すと `guide/api` フォルダーが開きます

フォルダーを開くと、その中のファイルがツリーで一覧表示されます。
フォルダーにもタグとアクセス許可があるので、ファイルと同じように設定できます。

### 3 つのアイコン

| アイコン | 何を出すか |
| --- | --- |
| **☰**（左上） | このフォルダーのファイル ツリー、新しいページの作成、検索、ヘルプ |
| **▤**（ファイル名の左） | このページの目次 |
| **🔓 / 🔒**（その右） | このページを見られる人 |

**☰ と ▤ は操作が同じ**です。

- **1 回押す** → その場にポップアップで出ます。もう一度押すと閉じます
- **2 回続けて押す（ダブル クリック）** → **画面の左に固定**されます。スクロールしても付いてきます
- 固定中に 1 回押すと閉じます

左に固定できるのは**どちらか一方だけ**です。目次を固定した状態でファイル ツリーを固定すると、
目次が閉じてファイル ツリーに入れ替わります。

**🔒 が閉じているページは限定公開**です。押すと誰が見られるか確認でき、
権限があれば変更もできます。

## タグ

### タグを編集する

タグの段の左にある**列名（「タグ」「分類」など）を押す**と編集画面が開きます。
選んで（または入力して）「保存」します。もう一度押すと閉じます。

**タグの列が 3 つ設定されていれば 3 段**出ます。一覧に無いタグを付けたいときは、
各段の「新しいタグを追加」の欄に入力してください（`;` か `,` で複数指定できます）。

この欄がグレーアウトしている列は、**選択肢以外の値を受け付けない設定**になっています。
管理者に列の設定を変えてもらってください。

保存すると、ファイル名の下のタグがその場で更新されます。

> **ライブラリの編集権限が必要です。** 閲覧のみの場合、保存時にエラーになります。

## 右上のボタン

環境によっては表示されないボタンもあります。

### 編集

SharePoint の編集画面を**新しいタブ**で開きます。ブラウザー上でそのまま編集できます。

### アプリで開く

このボタンは既定では表示されません。Web パーツの設定で有効にした場合に、ページ右上に表示されます。

`spmd:` という専用の合図でパソコンのアプリにファイルを渡します。

**対応したアプリが入っていないと何も起きません。** 少し待つと

> アプリを起動できませんでした。spmd: に対応したアプリがこの PC に登録されているか確認してください。

と出ます。この機能を使うには管理者側の準備が必要なので、必要であれば相談してください。
使わなくても閲覧・編集には支障ありません。

## 探す

☰ メニューの **「検索」** から検索ページを開けます。

| 選ぶもの | 内容 |
| --- | --- |
| **ページ名で探す** | ファイル名とフォルダー名から探します。すぐ結果が出ます |
| **本文で探す** | ファイルの中身を読んで探します。件数が多いと少し時間がかかります |
| **検索するフォルダー** | 空欄ならライブラリ全体。フォルダー名を入れるとその中だけ |
| **限定公開のみ** | 限定公開になっているページだけを出します |

結果はフォルダーのツリーで出るので、**どのあたりにあるページなのかが分かります。**

検索結果の URL はそのまま共有できます。

---

## ヘルプ

☰ メニューの **「ヘルプ」** から、このマニュアルを画面の中で読めます。
外部サイトを開く必要はありません。

---

## 表示を切り替える

☰ メニューの **「全画面表示に切り替える」** を押すと、SharePoint のナビゲーション類が
消えて本文だけが大きく表示されます。戻すときは同じ場所の
**「SharePoint 表示に切り替える」** です。

---

## ドキュメント ライブラリから直接開く

ページを経由せず、ライブラリからも開けます。

1. ドキュメント ライブラリを開く
2. `.md` か `.html` のファイルを**選択**する（クリックではなく、左のチェックを入れる）
3. ツールバー、または**右クリック メニュー**から選ぶ

| コマンド | 動作 |
| --- | --- |
| **SpWiki で開く** | ビューアー ページへ移動します |
| **Markdown プレビュー** | ライブラリの上にウィンドウが開き、その場で読めます |
| **デスクトップ アプリで編集** | パソコンのエディターで開きます |

**Markdown プレビュー**の中でもリンクを辿れます。
右上の「フルページで開く」で、そのドキュメントをページ側に引き継げます。

> コマンドが出てこない場合は、管理者側の登録がまだかもしれません。

---

## 表示されるメッセージ

| メッセージ | 意味 |
| --- | --- |
| `Loading...` | 読み込み中です |
| `ファイルが見つかりません。` | URL の `?file=` が指すファイルがありません。綴りを確認するか、リンク元の作成者に連絡してください |
| `ドキュメントライブラリが見つかりません。` | ページの設定が正しくありません。**管理者に連絡してください** |
| `ファイルを読み込めませんでした。` | 通信エラーか権限不足です。ページを再読み込みしても直らなければ管理者に連絡してください |
| `タグを保存できませんでした。` | ライブラリの編集権限がありません |

## よくある質問

**Q. 文書を編集したいのですが**

右上の「編集」ボタンで SharePoint 上で編集できます。使い慣れたエディターで書きたい場合は
「アプリで開く」を使ってください。書き方は [WRITERS_GUIDE.md](WRITERS_GUIDE.md) にあります。

---

## 開けないページに当たったとき

```
ファイルが見つかりません。
削除されたか、閲覧権限がない可能性があります。
                                    [戻る]
```

SharePoint は「存在しない」と「権限がない」を区別せずに返してくるので、
**どちらなのかはこの画面からは分かりません。**
下にはこのライブラリで開けるページのツリーが出るので、そこから移動できます。

**Q. 画面が狭く感じます**

URL の末尾に `&env=WebView` を足すと、SharePoint のナビゲーション類が隠れて本文が広くなります。

```
https://<テナント>.sharepoint.com/sites/docs/SitePages/SpWiki.aspx?file=README.md&env=WebView
```

**Q. 目次はありますか**

ドキュメントに「目次」という見出しがあれば、その下に自動生成されます。
無い場合は書いた人に追加を頼んでください（`## 目次` と 1 行足すだけです）。

**Q. 全文検索はできますか**

ビューアーには検索機能はありません。SharePoint 本体の検索をお使いください。

**Q. 印刷はできますか**

ブラウザーの印刷機能をお使いください。`&env=WebView` を付けてから印刷すると、
余計なナビゲーションが入りません。
