# 技術・運用リファレンス

SpWiki 1.0 の構成と運用上の注意事項をまとめます。
導入手順は [管理者向け](ADMIN_GUIDE.md)、ビルド手順は [開発者向け](DEVELOPERS_GUIDE.md) を参照してください。
文書内のテナント名・サイト名・人名は説明用のサンプルです。

## パッケージとバージョン

- 製品表記は **1.0**、npm は `1.0.0`、SPFx のソリューションとフィーチャーは `1.0.0.0` です。
- 配布ファイルは `packages/1.0.0.0/SpWiki.sppkg` です。
- パッケージのファイル名は `SpWiki.sppkg` に固定します。
- `npm run release` でクリーン、製品ビルド、パッケージ作成を実行します。
- `release/` はビルド用の一時出力です。配布物の保存先には使用しません。
- 配布時はデバッグ用バンドルの混入を避け、ファイルの内容・サイズ・SHA256を確認します。
- ソリューション・フィーチャー・コンポーネントの ID は製品の識別子です。環境のテナント ID ではありません。

## ページとコマンドの設定

- ライブラリのコマンドには、テナント全体への展開と拡張機能リストへの登録が必要です。
- `viewerPageUrl` には、ビューアーを配置したページの URL を指定します。
- `libraryRootUrl` と Web パーツの参照フォルダーを揃えてください。
- 設定の反映には時間がかかる場合があります。ページを再読み込みして確認してください。
- コマンド名はローカライズ用リソースから実行時に設定します。
- Single Part App Page はレイアウトを固定する用途です。設定を変更する場合は通常のページに戻します。
- `env=WebView` などの表示は SharePoint 側のページ構造に依存します。導入先で確認してください。

## ライブラリとタグ

- 日本語サイトの既定ライブラリは、表示名が「ドキュメント」、フォルダー名が `Shared Documents` の場合があります。
- リストタイトルとフォルダーパスを区別します。サブフォルダーはフォルダーとして解決します。
- タグはテキスト・複数行テキスト・選択肢・複数選択肢の列を扱います。
- 列の内部名と REST 応答のプロパティ名は一致しない場合があります。`EntityPropertyName` を使用します。
- 値の読み取りは文字列・配列・`results` を持つ形式を処理します。
- 自由入力の可否は `FillInChoice` に従います。ビューアーから列定義は変更しません。
- タグの絞り込みは取得したアイテムに対して行います。取得上限は `SharePointLibraryService.ts` の `ITEM_FETCH_LIMIT` を確認してください。
- ファイル編集の遷移先は親リストを基準にします。サブフォルダー直下に `Forms/AllItems.aspx` があるとは限りません。

## アクセス許可

SharePoint の利用者権限で読み書きします。ビューアーが権限を迂回することはありません。
継承の解除では既存の権限をコピーし、必要な対象を個別に変更します。
親フォルダーへの変更は、すでに独自権限を持つ子項目には反映されません。
導入先では、継承状態・権限の付与と解除・個別権限の子項目一覧を確認してください。

## 描画と安全性

- Markdown と HTML は共通のサニタイズ設定を通します。
- リンクや画像の属性を書き換える処理はサニタイズ後に行います。
- パスを正規化し、ドキュメントの拡張子を制限します。
- `style`、スクリプト、イベント属性など、許可していない要素・属性は除去します。
- 共通の表示クラスには CSS Modules の `:global()` を使用します。
- 非同期描画後に見出しへのスクロールを行います。
- デスクトップアプリ連携は `spmd:` に対応するアプリのインストールが必要です。

## 開発環境と検証

ビルド用の Node.js は `package.json` の要件に従います。
`npm run setup:node22` でプロジェクト内にポータブル環境を用意できます。

| 確認範囲 | 方法 |
| --- | --- |
| 中核ロジック・DOM描画 | `npm test` |
| ローカルでの表示・操作 | `npm run harness` |
| SPFx のコンパイルとパッケージ | `npm run release` |
| 権限・ライブラリ・コマンドの連携 | 導入先の SharePoint で確認 |

ローカルのモックは SharePoint の認証・権限・応答を再現しません。
導入先で必要な確認項目は [開発者向け](DEVELOPERS_GUIDE.md) に記載しています。
